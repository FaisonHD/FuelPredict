# FuelPredict
Eine Web-App, die aktuelle und historische Tankstellenpreise darstellt, analysiert und vorhersagt, wie sich der Preis einer Tankstelle wahrscheinlich entwickeln wird.

## Team

Ich arbeite alleine an FuelPredict (Einzelprojekt).

## Projektstand

Das Projekt enthält derzeit ein HTML-Grundgerüst und ein Suchformular. Die Suche zeigt noch keine echten Tankstellenpreise an; die Datenanbindung ist geplant.

## Entwicklung

`index.html` lässt sich lokal beispielsweise über VS Code Live Server öffnen. Die Browser-DevTools helfen beim Prüfen von HTML und Formularen.

## Noch selbst nachzuweisen (Übungsblatt 1 und 2)

- Tatsächliche Datenquelle ergänzen sowie Projektidee fristgerecht per E-Mail kommunizieren (falls noch nicht erfolgt).
- Tool-Versionen und Live Server lokal prüfen; DevTools-Versuch durchführen.
- Formularvalidierung und Tastaturbedienung selbst testen; Lighthouse Accessibility-Ergebnis dokumentieren.
- Sobald eine öffentliche URL existiert, diese in `sitemap.xml` eintragen und die Erreichbarkeit von `robots.txt`/`sitemap.xml` prüfen.
- Bonusaufgaben einschließlich eigener Begründungen und Rich Results Test gesondert bearbeiten.

Die Git-Historie enthält mehrere inhaltlich benannte Commits auf verschiedenen Tagen. Da es ein Einzelprojekt ist, sind keine Beiträge weiterer Teammitglieder erforderlich.
